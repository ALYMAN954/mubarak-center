# سجل متابعة دورات التجويد

موقع ثابت يعمل على GitHub Pages، وتُحفظ بياناته في قاعدة بيانات Supabase المجانية ليتشاركها الأساتذة والمشرف.

## الإعداد (مرة واحدة)

### 1) قاعدة البيانات
1. أنشئ حساباً على supabase.com ثم مشروعاً جديداً (الخطة المجانية تكفي).
2. افتح **SQL Editor**، والصق محتوى ملف `supabase/schema.sql` كاملاً، ثم اضغط **Run**.
3. افتح **Authentication ← Sign In / Providers ← Email** وعطّل خيار **Confirm email**. هذا ضروري لأن حسابات الأستاذين لا تستخدم بريداً حقيقياً.
4. افتح **Project Settings ← API** وانسخ قيمتين: **Project URL** و**anon public key**.

### 2) ربط الموقع
افتح ملف `config.js` واستبدل القيمتين:

```js
window.APP_CONFIG = {
  SUPABASE_URL: "https://xxxx.supabase.co",
  SUPABASE_ANON_KEY: "eyJ..."
};
```
المفتاح العام `anon` مصمم ليظهر في الموقع. الحماية تتم بقواعد قاعدة البيانات في `schema.sql`، فلا تضع أبداً مفتاح `service_role` في أي ملف.

### 3) النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub وارفع إليه كل الملفات (مجلد `assets` و`supabase` وملفات `index.html` و`config.js` و`sw.js` و`manifest.webmanifest` و`favicon.ico` و`.nojekyll`).
2. افتح **Settings ← Pages**، واختر **Deploy from a branch**، والفرع `main` والمجلد `/ (root)`، ثم احفظ.
3. بعد دقائق يظهر رابط الموقع في نفس الصفحة.

### 4) أول استخدام
افتح الرابط. أول زائر يرى شاشة «إعداد النظام» وينشئ حساب المشرف العام. بعدها يضيف المشرف الأستاذين من **الإدارة ← الأساتذة** بكلمة سر مؤقتة، ويغيّرها كل أستاذ عند أول دخول.

## كيف تعمل الحماية
- لا أحد يقرأ بيانات الطلاب دون تسجيل دخول.
- الأستاذ يرى ويعدّل دورته فقط، والمشرف يرى كل شيء.
- رابط الطالب يعرض بيانات ذلك الطالب فقط، دون ملاحظات الأستاذ ودون بيانات غيره.
- كلمات السر تدير Supabase تشفيرها، ولا يمكن لأحد عرضها.

## ملاحظات
- كلمة السر 6 أحرف على الأقل (حد Supabase الافتراضي).
- النسخة الاحتياطية من **الإدارة** تحفظ الطلاب والجلسات والإعدادات، ولا تحفظ حسابات الدخول.
- الخطة المجانية في Supabase توقف المشروع إذا لم يُستخدم أسبوعاً كاملاً، ويعود بضغطة زر من لوحة المشروع.

## ترقية إلى الإصدار 5 (نظام الدورات)

1. في Supabase افتح **SQL Editor** وشغّل محتوى الملف `supabase/migration_v5.sql` مرة واحدة (يسمح للأستاذ بأكثر من دورة).
2. ارفع `index.html` الجديد إلى GitHub (لا ترفع `config.js` فهو يحوي مفاتيحك).
3. الترتيب المقترح داخل التطبيق (حساب المشرف):
   - **الإدارة ← حفظ نسخة احتياطية**.
   - **الإدارة ← حذف البيانات السابقة** لتنظيف بيانات التجربة (اكتب كلمة «حذف» للتأكيد).
   - **الإدارة ← استيراد الدورات والأساتذة**: ينشئ 26 دورة و17 حساب أستاذ، ويعرض جدول كلمات السر المؤقتة مرة واحدة. انسخه أو حمّله PDF فوراً.
   - اكتب الفصل الدراسي (مثل «الأول») والعام الهجري في **الإدارة**.
4. الدرجة من 10، ومعدل الطالب = متوسط درجاته في الجلسات التي حضرها فقط. حدود الضعف والقوة والتنبيه تُضبط من **الإدارة**.

## تحديث v5 (الدورات والأساتذة والدرجات)

**الترتيب المطلوب للتحديث:**
1. في Supabase ← SQL Editor شغّل ملف `supabase/migration_v5.sql` مرة واحدة (يدعم أكثر من دورة للأستاذ).
2. ارفع `index.html` الجديد إلى GitHub (لا ترفع `config.js` ولا تغيّره).
3. سجّل الدخول مشرفاً ← الإدارة ← **حفظ نسخة احتياطية** (اختياري إن كانت البيانات تجريبية).
4. الإدارة ← **حذف البيانات السابقة** لتنظيف بيانات التجربة (اكتب كلمة «حذف» للتأكيد).
5. الإدارة ← **استيراد الدورات والأساتذة**: يضيف 26 دورة ويُنشئ 17 حساب أستاذ بكلمات سر مؤقتة. **احفظ الجدول (نسخ أو PDF) فوراً** فلا يمكن عرض كلمات السر لاحقاً. الاستيراد آمن للتكرار.
6. اكتب الفصل الدراسي (مثل «الأول») والعام الهجري في الإدارة.

**الجديد:** التنقل (القسم ← المجموعة ← الدورة)، الدرجة من 10 ومعدل الطالب على الجلسات التي حضرها، نقاط القوة والضعف مع ورقة PDF (حدودها من الإدارة)، جوال ولي الأمر وتعديل بيانات الطالب، أستاذ بأكثر من دورة، وحذف البيانات السابقة.

**إدارة الدورات كل فصل:** من تبويب «الدورات» افتح الدورة ← «إيقاف مؤقت / تفعيل الدورة» (تبقى بياناتها وتختفي من شاشة الأستاذ ومن التقارير)، ومن «الإدارة» يمكن تعديل اسم الأستاذ وتغيير دوراته.

**ميزات إضافية (v5.1):** إغلاق الفصل وأرشفته (الإدارة) مع تقرير PDF لأي فصل مؤرشف · تقرير نهاية الفصل ونشاط الأساتذة ورسائل التذكير (نظرة عامة) · استيراد قائمة طلاب من نص أو Excel · نقل جماعي للطلاب · شهادات المستحقين دفعة واحدة · بحث عام عن طالب · ترتيب الدورات داخل المجموعة بالأسهم.

**استيراد طلاب كل الدورات من ملف واحد:** املأ `قالب-استيراد-الطلاب.xlsx` (الدورة من قائمة منسدلة، الاسم، جوال الطالب، جوال ولي الأمر، رقم الإثبات، جهة العمل) ثم الإدارة ← «استيراد طلاب كل الدورات من ملف واحد» ← اختيار الملف ← معاينة ← تأكيد. وتصدير قائمة كل الطلاب من «نظرة عامة». وتظهر على الصفحة الأولى آية ﴿وَرَتِّلِ الْقُرْآنَ تَرْتِيلًا﴾ [المزمل: 4] وحديث «الماهر بالقرآن» (متفق عليه: البخاري 4937، مسلم 798).
